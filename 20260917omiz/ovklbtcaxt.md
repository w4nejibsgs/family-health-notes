# 【MY百科】儿内科专家提醒：夏季来袭，宝宝吃瓜需谨慎

> 更新时间：2026-09-17 (UTC+8)

**案例**

6月16日凌晨，江西省妇幼保健院儿内科病房来了一位因“发热、呕吐、腹泻”就诊的宝宝，外院门诊完善血常规白细胞及中性粒细胞百分比明显升高，C反应蛋白大于100mg/l，值班医师对患儿的病情有了初步的诊断。

**追问病史得知**：

患儿的保姆及阿姨均有腹泻、发热及呕吐的症状，并且有进食冰箱西瓜等冰冻食物史。结合患儿有不洁饮食病史，解黏冻大便，呕吐，高热，白细胞及中性粒细胞百分比明显升高，CRP大于100mg/dl，入院后完善降钙素原12.93ug/l。

临床诊断为：脓毒血症及急性胃肠炎。

**治疗方案**

儿内科医生针对患儿的病情，给予抗感染，纠酸、补液支持治疗，纠正低钠、低钾血症，指导饮食及护理等治疗。

目前，宝宝临床症状缓解，各项感染性相关指标下降。

三伏天就要来了

暑热夹湿，脾胃功能减弱，高温引起的食欲不振以及专属于夏天的凉食和冷饮成为了肠胃疾病的导火索。夏天温度高，湿度大，细菌和病毒等微生物容易滋生，剩饭剩菜饮食以及在冰箱内存放过久的非真空包装食物内细菌含量超标，进食后容易引起急性胃肠炎症状。使得夏季成为肠胃疾病的高发季节。

**常吃生冷食物警惕这些毛病！**

01**头 痛** 

刚从冰箱拿出的冰冻食品和口腔内的温度形成较大反差，口腔黏膜受到强烈刺激，引起头部血管迅速收缩痉挛，产生头晕、头痛甚至恶心等一系列症状。

02**胃 炎** 

吃太多冷食，突然出现上腹部阵发性绞痛，有时候窜到背部，严重时伴有恶心、呕吐、打冷战。这种胃炎不是真正的炎症，而是由于冰箱内所储存的食物或冷饮与人体胃内温差太大，引起的非炎症性胃痉挛。

03**肠 炎** 

人们习惯把生冷食品存放冰箱内慢慢享用。但是冷冻不同于杀菌消毒，如果食品放置不当或时间过久，仍可以出现发霉、变色等腐败变质现象。即使已冷却或冷冻的食品，仍会有少数低温微生物在活动。

**儿内科专家建议**

1、夏季饮食应清淡，避免生冷刺激食物的摄入，要规律作息时间，规律饮食，宜多吃新鲜蔬菜水果，补足水分，合理膳食，不要晚餐或深夜进食过多过饱。

2、从冰箱里拿出食物避免立即食用，尽量加热或放置至常温再食用，避免低温对胃肠道的刺激，引起胃肠功能紊乱。

3、避免进食在自然环境中存放过久或变质的食物，避免食物中毒及急性胃肠炎发生；特别提醒的是要注意个人及家庭人员手卫生问题，勤洗手，如家庭成员中有一人或人多出现发热、腹泻、呕吐等症状，需及时就医，以免延误病情。

**生冷食物易被细菌污染，五招预防感染！**

1、生熟食物分开，防止交叉感染；

2. 食物存放冰箱时间尽量短；

3. 确保彻底加热后再食用；

4. 定期清洗冰箱，最好每季度1次；

5. 不宜再加热，或者无法清洗的食物，老人、儿童孕妇与免疫力低下的病人，应避免食用。

儿内科门诊

**儿内科门诊诊治范围：**出生28天至14岁儿童。

**诊疗常见疾病：**流行性感冒，咳嗽，慢性咳嗽，支气管肺炎，支原体肺炎，毛细支气管炎，腹泻，急性胃炎，营养性疾病，蛋白质、能量营养不良，维生素缺乏症，麻疹，流行性腮腺炎，水痘，猩红热， 百日咳，手足口病，细菌性痢疾，EB病毒感染，婴儿肝炎综合征，巨细胞病毒性肝炎，泌尿道感染，缺铁性贫血，小儿热性惊厥，肥胖症等等。
