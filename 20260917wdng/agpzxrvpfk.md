# 市人民医院向全院干部职工发起疫情防控倡议……

> 更新时间：2026-09-17 (UTC+8)

//  **倡议书** //

全院广大干部职工：    

　　近期，根据全市疫情防控工作形势，我院严格贯彻落实市委市政府工作部署，全力做好检测点体温监测、核酸检测、院感防控、医疗救治、医疗支援等各项任务，充分发挥基层党组织战斗堡垒和党员先锋模范作用，广大党员、团员、干部职工闻令而动、冲锋在前，党旗在一线高高飘扬、党徽在闪耀，展现了市人民医院人的社会担当。为进一步做好疫情防控与医疗救治工作，现向广大干部职工倡议如下：

**　　一是勇于担当，提高政治站位。**党有号召，我们有行动。疫情期间，全院广大干部职工坚守在防控一线，党员、团员亮身份、见行动、作表率，展现了关键时刻讲政治、讲大局的精神风貌。全院上下要进一步增强做好疫情防控和医疗救治工作的责任感，提高政治站位，党员要落实好“四个带头”要求，凝聚全院力量，劲往一处使，全力打赢疫情防控阻击战。

**　　二是履职尽责，落实防控措施。**在上级疫情防控统一部署下，医院组成专家医疗队，组织百余名医护人员奔赴一线，协助五莲开展疫情防控和医疗救治工作，采取互联网医院在线咨询服务等一系列措施满足群众就医需求。全院广大干部职工要一如既往，带头服从医院工作部署，履职尽责，奋勇争先，加强对来院就诊群众宣传引导，科学理性应对疫情，以扎实行动推动各项工作任务落实到位。

**　　三是争作表率，营造良好环境。**生命高于一切，安全重于泰山。全院广大干部职工要带头落实个人防护要求，带头加强健康监测，密切关注本人及家人健康状况。党员、团员要带头参与检测点体温监测、互联网在线咨询等志愿服务，奉献爱心，把健康知识宣传给广大患者，把党的温暖传递给广大群众。始终讲政治、顾大局、守纪律,不信谣、不传谣，营造良好舆论氛围。

　　疫情就是命令，防控就是责任。广大党员、团员要带头以实际行动践行初心使命，带动全院干部职工以无畏精神展现担当作为，在疫情防控中树好形象，在服务群众中争做先锋，让党旗在疫情防控和医疗救治工作第一线高高飘扬！
