# 国内三胎做试管正规医院给做吗？

> 更新时间：2026-09-19 (UTC+8)

我结婚已经有七八年了，现在已经有两个孩子，都是女儿。虽然我和我老公都觉得儿子女儿都无所谓，但是家里的老人就一直说要我们再生一个，说万一是儿子呢。于是我和我老公就去医院做了检查，医生说我们目前的情况自然怀孕比较困难。我想到可以做试管，但是我国现在还是实行的二胎政策，三胎只是在讨论阶段。那国内三胎做试管正规医院给做吗？ 
查看全部内容

目前国内还是实行的二胎政策，像你已经有两个孩子的情况再生三胎属于违反计划生育。如果是自然怀孕，最多就是交罚款，但是三胎做试管正规医院是不给做的。并且做试管婴儿也是有条件的，你目前的情况并不满足做试管的条件。
输卵管性不孕症、原因不明的不孕症、子宫内膜异位症、男性因素不孕症(男方重度少弱精，或男方无精症，需经睾丸或附睾穿刺获取精子者)、排卵异常(经一般的促排卵治疗无成熟卵泡生长)、宫颈因素等不孕症患者，通过其他的常规治疗之后仍然无法妊娠等情况。如果夫妻双方有以上这些情况，可以先到医院进行相关的检查，让医生明确可以做试管婴儿之后，再进入试管婴儿的手术周期。
虽然现在有提出要实行三胎政策的意见，但只是在讨论阶段，并没有发布明确的规定。所以现在还是实行二胎政策，只有以下几种情况才能生三胎，即：

- 1. 夫妻已经生育两个子女，但是如果有子女经过鉴定是病残儿，无法成为正常的劳动力，并且在医学上也认为其能够再生育的；
- 2. 夫妻无法生育，依法收养了两个孩子后，有能力生育的，可以再生一个孩子；
- 3. 再婚的夫妻一方已生一个子女，而另一方未生育，在再婚后双方已生育一个子女的；
- 4. 再婚的夫妻一方已生两个子女，另一方未生或已生一个子女，双方再婚后未生子女的；
- 5. 再婚的夫妻各生一个子女，且再婚后共同生育一个子女的；
- 6. 省人民政府计划生育部门认定的其他情况。
国家相关部门发布了全面二胎开放生育政策，规定符合国家法律、法规规定条件的可以生育两个子女。对于什么时候放开三胎政策目前相关部门并没有发布明确的规定说明，具体的全面开放三胎时间以国家发布的规定为准。
