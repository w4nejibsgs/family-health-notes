# 全国2亿多人中招！会癌变！逆转只需这么做

> 更新时间：2026-09-16 (UTC+8)

根据有关数据显示全球100个人中就有20-30个人患有脂肪肝相信有不少人在体检中也被诊断出有脂肪肝并且越来越多年轻人被脂肪肝盯上脂肪肝要紧吗？如果你觉得它要紧（重视并改变不良生活习惯）它可能对你的健康影响就不太大（可逆转）如果你觉得它不要紧那么小心它悄悄变成肝炎然后肝硬化最后到肝癌没错脂肪肝会变肝癌那么怎么逆转脂肪肝？这三点很关键
**为什么脂肪肝找上我？**

“医生，我又不胖，为什么也会得脂肪肝？”浙江大学医学院附属第一医院健康管理中心营养师刘沉冰表示，在很多人印象中脂肪肝是肥胖人士才会得的，但根据每年体检情况看，很多长得不胖的年轻人也不断“中招”。

这些不胖的人群，虽然皮下脂肪较少，但内脏脂肪可能相对较多，平时多有饮酒、熬夜、喜甜食、不运动等不良生活饮食习惯，这些都可能会造成脂肪存储的负担，引发脂肪肝。脂肪肝一般分为酒精性脂肪肝和非酒精性脂肪肝。酒精性脂肪肝，顾名思义就是由于摄入大量酒精导致，而后者可能由于营养过剩和胰岛素抵抗引起的慢性进展性肝病。轻度脂肪肝可以通过调节生活、饮食习惯逆转。如果任其发展不管，那么脂肪肝可能就会进展为肝炎、肝硬化、肝癌。那么体检出脂肪肝，该怎么做？

**得了脂肪肝，这么做**

**1**

**戒酒第一**

如果是酒精性脂肪肝，首当其冲就是戒酒。不过，哪怕不是酒精性脂肪肝，也建议戒酒。
酒精伤肝众所周知，最好的做法是滴酒不沾。如果工作需要一定要喝酒，则需要限制饮酒并避免一次性过量饮酒。中国居民膳食指南（2022版）建议，成年人如果饮酒，一天饮用的酒精量不超过15g。含有15g酒精的不同类型的酒量，大概相当于酒精度为4%的酒450ml （如一些啤酒），酒精度为12%的酒150ml（如一些葡萄酒），酒精度为43%的酒50ml （如白酒，少于一两），酒精度为52%的酒36ml （如高度白酒，半两多）。一般会通过下面的公式可以计算出一定体积的酒或含酒饮料中的酒精克数。含酒精克数 = 0.8 x 体积（ml） x 度数（% vol. ）/ 100。
**2**

**控制体重**

对于超重肥胖的脂肪肝患者来说，控制体重确实非常有必要。
指南指出，超重/肥胖患者需要通过改变生活方式使体质量减轻7-10%, 可降低肝功能指标和改善肝组织学损伤；对于瘦型脂肪肝，体质量减轻3-5%就足够了。

**科学减肥**
科学减肥的关键是控制总热量、保持血糖稳定，同时实现营养均衡。减重是一个长期的过程，养成良好的生活方式和均衡的饮食结构才是减重并可维持的最佳策略。

**勿节食**
指南还指出，脂肪肝患者需要避免极低能量的饮食方式去减肥，因为这可能会导致肝损伤加重。

**晚饭还是要吃的**
晚饭不但要吃，还应该好好吃。尤其是对于午餐吃外卖的人来说，可以利用晚餐补充新鲜的蔬菜，以及全谷物类的主食，同时补充优质的蛋白质，比如鱼虾、鸡胸肉、瘦牛肉等。
需要注意的是，晚餐的食物种类不可少，但是总量可以适当少吃一些；当然吃晚餐的时间可别太晚了哦。

**3**

**坚持运动**
保证每周150分钟的中等强度有氧运动，以及至少两次的抗阻训练；避免久坐少动，同时找到自己感兴趣并能坚持的体育锻炼方式。例如：每天快走40分钟，一周4次；或者每天慢跑30分钟，一周5次。
